# ce-motion (v3.0.0)
The motion design engine: image ads, carousels (static + live), animated ads, kinetic type, logo stings, interactive ads, app UI motion, pitch decks. Never invents a photo; orders people and footage by ticket from ce-realism or ce-cinematic. Runs the ce-core spine (submodule `core/`).

Read order: core/SKILL.md → SKILL.md → intake.md → sound.md → the format file (image-ads, carousel, animated, pitch-deck) → library/.
