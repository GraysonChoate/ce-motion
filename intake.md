# ce-motion intake (gap questions; core/intake.md ranks and caps at 5, one block)
Ask only what the request and research don't answer; the rest are proposed in the brief. Ranked, most important first.

| # | Ask | Propose by default |
|---|---|---|
| 1 | Format: image ad / carousel / live carousel / animated ad / logo sting / interactive / deck | From where it runs and the goal |
| 2 | Does it need people or lifestyle photos? | If yes, which look: phone-real (ce-realism) or styled (ce-cinematic) |
| 3 | Angle (3 options) | From research: benefit, ingredient/proof, offer |
| 4 | Motion words (3 adjectives) | From the brand bible; else from the brand voice |

Proposed, never asked: number of pieces (from the request), length (from the placement band, core/export-table.md), sound (silent-first; SFX + music on video).
Derived, never asked: ratios, sizes, safe zones, slide size, BPM default, fps, specs.
Standard method, never asked: exact copy list; text in code; real pack rendered in-scene from a packshot reference (never composited); stills before motion; native layout per ratio; frame sheet audit.
