# ce-motion intake (gap questions; Core asks the 5 universal ones first)
Ask only what the user didn't say. Each with a proposal. Max 5 across Core + engine.

| Ask | Propose by default |
|---|---|
| Format: image ad / carousel / live carousel / animated ad / logo sting / interactive / deck | From where it runs and the goal |
| How many pieces? | 3 concepts × every ratio |
| Angle (3 options) | From research: benefit, ingredient/proof, offer |
| Does it need people or lifestyle photos? | If yes, which look: phone-real (ce-realism) or styled (ce-cinematic) |
| Motion words (3 adjectives) | From the brand bible; else proposed from the brand voice |
| Sound | Silent-first; SFX + music on video pieces |
| Length (video) | 6 / 10 / 15 s by placement |

Derived, never asked: ratios, sizes, safe zones, slide size, BPM default, fps, specs.
Standard method, never asked: exact copy list; text in code; real pack composited; stills before motion; native layout per ratio; frame sheet audit.
