# Static image ads (ce-motion)
Spine and gates: SKILL.md. This file holds only what static ads add.

## Concepts
5 angles from research and the bible: benefit · ingredient/proof · routine/lifestyle · offer · comparison · social proof from real reviews only. Step 3: 3 directions (safe → bold); the user picks 1; then 3+ concepts inside it from these angles.

## Routes (pick per concept)
- **A · Fast** (default: Firefly stills + code layout; Higgsfield Ads Studio only if asked): get_workflow_instructions("ads-studio"); ads_studio_create_brand + add_product (page URL + packshots); quote, wait for yes, generate. Ratios 1:1, 9:16, 16:9, 3:4 (no 4:5: crop from 3:4 or use B). Output = concept drafts (preset rule: SKILL.md §How this engine thinks).
- **B · Accurate (locked-pack composite)** when the label must be exact: build the scene without the pack (supplier ticket: ce-cinematic styled, ce-realism phone-real), composite the real transparent packshot on a measured surface line with contact shadow and matching light; if a model rendered the pack, OpenCV-align and overlay the true label, verify. Scene and light recipes: get_workflow_instructions("product-photoshoot").
- **C · Templated scale (Canva)**: brand template; autofill headline/price/CTA/packshot; resize-design to every ratio; export.
Any generated scene, people or lifestyle: supplier ticket (SKILL.md §How this engine thinks).
Failure: generic Ads Studio copy → re-run add_product with the product page and photos, then generate.

## Finish
Text, logo, price, CTA in Canva or code. Keep text light (Meta recommendation, not a rule). Safe zones from core/export-table.md. Export every concept at every ratio the named placements need.

## Deliver
Ad set folder + contact sheet + spec table (ratio, size, file). A test plan only if the user asks.
