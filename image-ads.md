# Static image ads (ce-motion)
Spine and gates: SKILL.md. This file holds only what static ads add.

## Concepts
5 angles from research and the bible: benefit · ingredient/proof · routine/lifestyle · offer · comparison · social proof from real reviews only. Step 3: 3 directions (safe → bold); the user picks 1; then 3+ concepts inside it from these angles.

## Routes (pick per concept)
- **A · Fast** (default: stills from the still-text capability + code layout; a tool's ad preset if the user asks): give it the product page and real packshots; quote, wait for yes, generate. Ratios per the tool (no native 4:5: crop from 3:4 or use B). Output = concept drafts (preset rule: SKILL.md §How this engine thinks).
- **B · Accurate (packshot-guided)** when the label must be exact: lay out the scene with the real packshot placed and turned to the exact angle as a reference image, then generate the final image with the model rendering the pack in the scene's light (real packshot = reference only (core SKILL.md rule 2)). Label wrong = regenerate with the cause changed; never composite the pack or overlay a label. Scene and light recipes: get_workflow_instructions("product-photoshoot").
- **C · Templated scale (Canva)**: brand template; autofill headline/price/CTA/packshot; resize-design to every ratio; export.
Any generated scene, people or lifestyle: supplier ticket (SKILL.md §How this engine thinks).
Failure: generic preset copy → re-run with the product page and real photos, then generate.

## Finish
Text, logo, price, CTA in Canva or code. Keep text light (Meta recommendation, not a rule). Safe zones from core/export-table.md. Export every concept at every ratio the named placements need.

## Deliver
Ad set folder + contact sheet + spec table (ratio, size, file). A test plan only if the user asks.
