# Static image ads (ce-motion)
Spine and gates: SKILL.md. This file holds only what static ads add.

## Concepts
5 angles from research and the bible: benefit · ingredient/proof · routine/lifestyle · offer · comparison · social proof from real reviews only. Pair concepts by mood for A/B (calm vs bold).

## Routes (pick per concept)
- **A · Fast (Higgsfield Ads Studio)**: get_workflow_instructions("ads-studio"); ads_studio_create_brand + add_product (page URL + packshots); quote, wait for yes, generate. Ratios 1:1, 9:16, 16:9, 3:4 (no 4:5: crop from 3:4 or use B). Output = concepts to check, not finals.
- **B · Accurate (locked-pack composite)** when the label must be exact: build the scene without the pack (supplier ticket or board model), composite the real transparent packshot on a measured surface line with contact shadow and matching light; if a model rendered the pack, OpenCV-align and overlay the true label, verify.
- **C · Templated scale (Canva)**: brand template; autofill headline/price/CTA/packshot; resize-design to every ratio; export.
Lifestyle or people in the ad: order from ce-realism (phone-real) or ce-cinematic (styled) by ticket.

## Finish
Text, logo, price, CTA in Canva or code. Text under ~20% of the image. Safe zones from the export table. Export every concept at every ratio.

## Deliver
Ad set folder + contact sheet + spec table (ratio, size, file) + A/B plan (what each pair tests, metric) if asked.
